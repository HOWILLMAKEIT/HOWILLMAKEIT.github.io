# 个人主页时间地图维护

地图位于 `/about/#journey`，由 `layouts/_partials/profile-journey.html` 渲染，样式为 `assets/css/extended/profile-journey.css`。一行一个学年（9 月至次年 8 月），彩色区间可点击；手机端在图内左右滑动。小屋首页的「时间地图」按钮直接打开这里。

## 修改内容

唯一数据源是 `data/profile.json`：

- `education`、`tracks[].entries`、`project` 存放详细经历；每项 `id` 是地图的跳转锚点，原有 ID 不要随意改动。
- `journey.years[]` 目前只画大一至大四；研究生阶段尚未开始，不预置空行。每个学年从 **9 月到次年 8 月**，`events[]` 中的 `start` / `end` 默认是 1—12 的含首尾月份序号（1=9 月，4=12 月，7=3 月，10=6 月，12=8 月）；跨学年的经历在相邻学年各画一段。
- `lane` 指区间所在的上下排位，`lanes` 是该学年的总排数。同类优先排同一层；例如大三科研用 1、2 层（重合时错层），个人项目用 3 层，两段实习共用 4 层，开源用 5 层。同一排的区间不得重叠。`ref` 指向详细经历的 `id` 或段落 ID，`label` 是图上标题，`caption` 是标题下的一行小字，简写时间与事项／身份，科研项目注明作者位次；`kind` 决定颜色。`period` 用于无障碍朗读与日期核对（不在色条下重复显示）；未填写时取详细经历的 `date`。
- **仅在主要投入期与论文里程碑日期不同、且有来源时**才写 `period`。LCC-CMAES 的主要投入期是 2025.10—2026.01；用户最新更正 LDO 从 **2026.01** 开始，至 2026.06。这些都不是投稿或录用时间。Meta² 按用户更正从 **2026.09 起**标注「在研」，`ongoing: true` 表示尚未提供结束月份。
- 大二下的「加入课题组」是阶段示意，不表示精确入组日。用户确认主页按骑士集团截至 **2026.06.30**、南方电网 **2026.07—08** 展示，已同步主页详情（简历源文件尚未改）。骑士区间的 `end: 11, endAtStart: true` 表示色条止于 **7 月刻度起点**，即画到 6 月末；南方电网 `start: 11` 从 7 月起点接续。

## 验证

在站点根目录运行：

```bash
hugo --destination /tmp/profile-journey-check --cleanDestinationDir
python3 scripts/verify_profile.py /tmp/profile-journey-check
```

验证器检查地图引用、目标锚点、三条经历时间轴和本地链接。发布前仍需在手机与桌面尺寸确认可读性；推送会触发 GitHub Pages 部署，本地构建不发布。
