# 个人主页时间地图维护

地图位于 `/about/#journey`。模板是 `layouts/_partials/profile-journey.html`，样式是 `assets/css/extended/profile-journey.css`，唯一内容源为 `data/profile.json` 的 `journey` 字段。

## 布局

每个学年从 9 月到次年 8 月。项目名称、日期和说明放在对应花括号上方；录用、汇报等里程碑文字放在圆点上方。学年的月份轴位于底部。同类且时间不重叠的经历可共用一排：两段实习按 4—6 月、7—8 月接续，文字居中放在各自的花括号上方。科研投入期重叠时分排；LCC 的投入花括号与录用、Oral 圆点仍在同一行。靠右端的标签向左收纳并右对齐。

手机端保留横向月份比例，文字使用整行宽度自动换行，仍位于花括号上方，不需要横向滚动。LCC 的两个里程碑在手机端另留标注空间。明暗主题共用结构与数据。

## 数据语义

- `years[]` 表示大一至大四，`label` 为学年，`range` 为实际年月，`chapter` 为简短阶段名。
- `events[]` 的 `start` / `end` 为含首尾的月份序号，1=9 月、5=1 月、12=8 月。`lane` 是排位，同排的项目使用相同值；共用一排时设置 `shared: true`，每项仍按实际月份占宽。窄屏会分排展示，保持文字和日期完整。
- `ref` 指向教育、实习、科研、开源或学术服务的既有详情锚点。`label` 是标题，`period` 是显示日期，`caption` 是身份或进展。`kind` 决定颜色。
- `endAtStart: true` 表示结束于 `end` 月起点。骑士集团的 `end: 11` 因而截至 6 月末，南方电网从 `start: 11` 的 7 月开始。
- `point: true` 表示单个节点；`day` 可注明日，没有日则仅按月份示意，页面不推测具体日期。
- `milestones[]` 的 `month` 使用相同的学年月份序号，`date` 保留完整日期。LCC 主要投入期为 2025.10—2026.01，录用为 2026.03.20，Oral 为 2026.07.17；不以成果日期延长投入区间，也不将会议投稿截止日当成本人的实际投稿日。
- `ongoing: true` 标记在研，花括号画至 `asOf` 所在月；更新记录日期时须同步核对区间结束月份。在研项目从 2026.09 起，在研且尚未投稿。
- Open Code Review 横跨大三与大四，分别以 `continues` / `continued` 标注续接，完整日期均为 2026.08—09。
- `affiliation` 展示持续的实验室经历，MetaEvo 入组日为 2025.04.15。
- `undated[]` 展示没有明确发生日期的事项。硕士拟录取独立列为下一阶段，预计 2027.09 入学，不放在猜测的录取日期上。

本次日期与事项依据用户提供的《郭昊 人物志.md》（资料核对日期 2026-10-06）。页面采用网页布局，未复制 Obsidian 中的绘图组件。人物志原文件保持不变。

## 验证

```bash
hugo --destination /tmp/profile-journey-check
python3 scripts/verify_profile.py /tmp/profile-journey-check
```

验证器检查时间语义、共享数据、详情锚点和本地链接。浏览器还需检查桌面和手机宽度、深色模式、文字位于花括号上方且无重叠。推送会触发 GitHub Pages 部署；本地构建不发布。
